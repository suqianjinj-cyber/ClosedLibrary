# 模型清單（給 Tripo 3D 製作用）

目前場景裡的家具都是方塊組成的佔位模型。照這份清單做出精細模型後，放進 `assets/models/tripo/`，再告訴我要替換哪一項，我會負責換上，不需要改程式。

## 共通規格

| 項目 | 規格 |
|---|---|
| 匯出格式 | **GLB**（含貼圖） |
| 單位 | 公尺，尺寸請接近下表 |
| 原點 | 物件**底部中央**（放在地板上剛好貼地） |
| 貼圖 | 1024×1024 為主；櫃檯等重點物件最多 2048×2048 |
| 面數 | 見下表「三角面上限」；Tripo 匯出時選低面數（Low Poly）或設定面數上限 |
| 風格 | 寫實、老舊、略髒；顏色偏暗，避免高彩度 |
| 方向 | 不用特別處理，我匯入時會轉正 |

面數和貼圖越小，文書筆電跑起來越順。同一種家具在場景裡會重複擺很多個（例如書架 84 座、椅子 36 把），所以這類物件特別要控制面數。
