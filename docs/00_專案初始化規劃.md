## 2. 資料夾結構（已建立，均為空資料夾）

採「依功能分資料夾」：場景（.tscn）與它的腳本（.gd）放在同一個資料夾，初學者比較好找。

```

  textures/ materials/ fonts/ ui/
  audio/sfx/ ambience/ voice/ recordings/ music/

  rules/           各層「須知」告示
```

## 3. 系統責任分工

### 3.1 全域系統（core/，註冊為 Autoload）

| 系統 | 負責 | 不負責 |
|---|---|---|
| `EventBus` | 只宣告訊號（玩家被抓、發出聲音、關卡完成…），讓各系統互相通知而不互相依賴 | 任何邏輯 |
| `GameState` | 目前關卡、重傷狀態、第二層駁回次數、手機電量、劇情旗標 | 畫面、音效 |
| `DataLoader` | 依 id 讀取 `data/` 下的 JSON，回傳字典；讀取失敗時印出清楚錯誤 | 解讀內容 |
| `LevelManager` | 淡出 → 換場景 → 淡入；重生點；重新開始本層 | 關卡規則 |
| `AudioManager` | 播放音效／環境音、音量匯流排（Master/SFX/Ambience/Voice） | 怪物「聽到」與否（那是玩法，見 NoiseEmitter） |

### 3.2 玩家（player/）
- `player.tscn`：`CharacterBody3D` + 攝影機 + 手機手電筒（`SpotLight3D`，無陰影或低解析陰影）
- 移動：走、蹲、跑；滑鼠視角；ESC 釋放滑鼠
- 喘氣值：跑步上升、靜止下降；過高時發出氣音
- 發出聲音時呼叫 `NoiseEmitter`，由敵人的聽覺元件接收
- 狀態：正常／重傷（第三層用，降低速度）

### 3.3 互動（interaction/）
- 玩家前方一條 `RayCast3D` 偵測可互動物件
- 共用元件 `Interactable`：提供「提示文字」與 `interact()`；告示、書、耳機、電話都用它
- `HidingZone`（`Area3D`）：標記陰影／躲藏區

### 3.4 敵人（enemies/）
- 共用感知元件：`VisionCone`（館員手電筒光束）、`HearingSensor`（奔跑者聽聲音）
- 每個敵人用簡單狀態機：巡邏 → 察覺 → 追擊 → 抓到
- 各層特殊行為寫在各自資料夾，不放進共用元件

### 3.5 UI（ui/）
- `hud`：互動提示、喘氣值、手機電量／訊號格
- `stream_chat`：直播彈幕，內容來自 `data/chat/`
- `notice`：顯示「須知」告示，內容來自 `data/rules/`
- `qte`：第三層「扯開魚叉」連打條
- `menus`：暫停、設定（滑鼠靈敏度、音量）

### 3.6 關卡（levels/）
- 每層一個 `LevelController` 腳本：只管該層的勝負條件與流程
- 數值（秒數、次數）放 `data/levels/`，不寫死在程式中

### 3.7 劇情資料原則
- 所有中文台詞、告示、彈幕都放 `data/` 的 JSON，程式中只出現 id（例如 `"prologue_caught"`）
- 改劇情只改 JSON，不用動程式

## 4. 第一個可玩原型：建議做「現實開場・巡邏館員（教學關）」

理由：它沒有超自然元素、威脅低，但會用到後面所有關卡的底層（移動、躲藏、喘氣、偵測、失敗重來、換關），做完等於把地基打好。

| 里程碑 | 內容 | 驗收標準（你可以自己測） |
|---|---|---|
| M0 專案建立 | 用 Godot 4.7.2 建立專案（Compatibility）、Git 初始化、`.gitignore` | Godot 專案管理器打開不報錯；專案設定 → Rendering → Renderer 顯示 Compatibility；`git status` 不會出現 `.godot/` 資料夾 |
| M1 玩家移動 | 灰盒房間（方塊地板、牆、書架） + 第一人稱移動 | WASD 移動、滑鼠轉頭、Shift 跑、Ctrl 蹲、ESC 放開滑鼠；不會穿牆；筆電上 FPS ≥ 30（偵錯器 → 監視器） |
| M2 互動 | 看著告示按 E 顯示文字 | 準心對準時出現「按 E 閱讀」；內容來自 JSON，改 JSON 後重開遊戲文字跟著變 |
| M3 喘氣與躲藏 | 喘氣值條 + 陰影區 | 跑 3 秒以上喘氣值明顯上升；停下後會下降；進入陰影區 HUD 有提示 |
| M4 巡邏館員 | 沿固定路線巡邏、手電筒光束偵測 | 站在光束內會被抓；躲在陰影且喘氣值低不會被抓；喘氣值高時躲著也可能被發現；被抓後淡出、顯示館員台詞、回到潛入點 |
| M5 開播與轉場 | 抵達死角 → 開播 → 停電 → 換到佔位的第一層 | 彈幕出現在畫面上；燈全滅後載入第一層灰盒場景；整段流程可從頭玩到尾不當機 |

每個里程碑完成後提交一次 Git，並在 `tests/` 寫下對應的手動測試清單。

## 6. 效能原則（文書筆電）
- 只用 Compatibility 渲染器；不開 SDFGI、體積霧、SSAO 等進階效果
- 光源以少量 `OmniLight3D`／`SpotLight3D` 為主，大部分關閉陰影；需要時用烘焙光照
- Tripo 模型匯入前減面，單一模型建議數千三角面以內
- 恐怖感優先靠音效、黑暗、霧（Compatibility 支援的基本霧）而不是高畫質
